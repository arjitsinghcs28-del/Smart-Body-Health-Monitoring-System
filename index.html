PROJECT OVERVIEW

About This Prototype

A software-only college project demonstration.

◎

Objective

Demonstrate a user-friendly workflow for image upload, preview, and report presentation without special hardware.

⌘

Technology

HTML for structure, CSS for styling, and JavaScript for image preview, navigation, and demo history.

⚠

Limitations

This version does not use a trained medical AI model and does not diagnose or calculate real health parameters.

Possible future improvements

  • Connect a validated computer-vision model for a clearly defined task.
  • Add consent, secure storage, and deletion controls if a backend is introduced.
  • Validate any medical use with qualified professionals and appropriate clinical evidence.
