# Smart Body Health Monitoring System Using Contactless Body Scanning

## 📌 Project Overview

The **Smart Body Health Monitoring System Using Contactless Body Scanning** is a project focused on exploring contactless techniques for preliminary body health monitoring.

The project studies different possible sources of pain, their causes, and the observable features that may be associated with them. It also explores how camera-based techniques may help observe certain visible features without direct physical contact.

The project is currently under development, and the work is being carried out in phases.

## 🎯 Objectives

- Study how pain occurs and identify its possible sources.
- Classify pain-related sources such as skin, muscles, bones, joints, nerves, and other internal causes.
- Identify observable and non-observable features associated with different types of pain.
- Explore the potential and limitations of contactless, camera-based observation.
- Develop a structured pain classification tree.
- Establish a foundation for possible future machine learning integration.

## ✨ Current Features

- Basic web-based frontend.
- Home, Scan, History, and About sections.
- Image upload interface for supported image formats.
- Demonstration interface for displaying sample results.
- Pain classification and research work developed as part of the project.

**Note:** The current interface is a prototype. It does not perform validated medical diagnosis or actual health-parameter measurement. Demonstration results are placeholders and should not be interpreted as real measurements.
